# Stream Recorder

Record MP3 web radio streams on a schedule – track list and chapters from the stream
titles, ID3 tags, recordings browser, lossless cutting into single tracks with covers,
trash folder, sensors and events for automations. German and English.

Zeitgesteuerte Aufnahme von MP3-Webradio-Streams – Titelliste und Kapitel, ID3-Tags,
Aufnahmen verwalten, verlustfrei in Einzeltitel schneiden mit Cover-Suche, Papierkorb,
Sensoren und Ereignisse für Automationen. Deutsch und Englisch.
